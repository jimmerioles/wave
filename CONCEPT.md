# Wave — the playable synth

A landing page for a browser synth where the hero is the instrument.

Hold keys to play notes. The orb and particles react to the audio; the page becomes a small playable instrument. The interaction is the product: no video, no fake waveform, just sound you make.

## First build

1. Static page with a keyboard map and a central visualizer.
2. Web Audio oscillators, a filter, an envelope, and a master bus.
3. Pointer and keyboard input with polyphony.
4. Particles or a canvas waveform that reacts to the analyser.
5. Presets, mobile layout, reduced motion, and a 60-second demo.
